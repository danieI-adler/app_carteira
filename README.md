#  app_carteira

A **** é uma plataforma web de simulação de investimentos. O sistema opera como uma competição permanente de gestão de portfólio utilizando ativos reais negociados na B3 (ações, ETFs, FIIs, BDRs, etc.), permitindo que os participantes tomem decisões, com capital fictício.

---

https://daniei-adler.github.io/app_carteira/

##  Funcionalidades Principais

### Para Participantes (Equipes)
* **Capital Inicial:** Cada equipe inicia com um saldo fixo de **R$ 100.000.000,00** em caixa.
* **Gestão de Portfólio:** Consulta de patrimônio líquido, caixa disponível, posições compradas/vendidas, lucro/prejuízo acumulado e histórico completo.
* **Sistema de Ordens:** Envio de ordens *A Mercado* e *Limitadas* (Preço fixo).
* **Venda a Descoberto (*Short Selling*):** Permitida contanto que consuma margem operacional dentro do limite do patrimônio líquido disponível.
* **Rendimentos e Proventos:** Crédito automático em caixa de dividendos, JCP, rendimentos de FIIs e atualização de rendimento sobre o caixa.
